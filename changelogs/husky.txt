DerpFest v17 (Android 17) for the Pixel 8 Pro (husky), build 20261023
Security patch: 2026-10-01 (system), 2026-08-05 (vendor). Stock Pixel firmware: bootloader-husky-ripcurrent-17.0-15681527.img + radio-husky-g5300i-260604-260807-b-16036236.img.

Notes:
==============================
- Unofficial build, signed with its own keys: updates from other ROMs (Evolution X included) don't install on it, and moving between ROMs needs a clean install.
- The update includes the stock Pixel firmware (bootloader and radio).
- Rooted? Before rebooting, install Magisk (or KernelSU) to the inactive slot, or root is gone after the update.
- Kernel: LineageOS's gs-6.1 kernel (Linux 6.1), built from source with the ROM.
- First installs need a computer: see https://xdaforums.com/t/4805779/

Device changes:
==============================

ROM changes since the last build:
==============================
- Apps restored from your Google backup during setup keep their network access (the per-app Network access setting was turned off for some of them)
- App Lock: Recents Screenshot, Lens and split screen no longer show a locked app's last screen
- USB debugging (ADB) is off by default again and asks for authorization on your computer
- Removed the experimental Play Integrity spoofing layer from the first build; DerpFest's own attestation handling is back
- Kernel 6.1.162 (LineageOS gs-6.1, android14-6.1-2026-03)
