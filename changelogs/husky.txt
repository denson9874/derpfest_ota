End of support: DerpFest for the Pixel 8 Pro (husky)

These unofficial DerpFest builds are no longer maintained. denson9874 no longer builds or supports DerpFest, so no more updates will come through this feed. The last build was DerpFest-v17-20261024-husky-Unofficial-Stable.zip, and the old downloads are being taken down.

Where to go next:
==============================
- ExpressiveOS is denson9874's own ROM for this phone, built on LineageOS and AOSP, with monthly updates over the air.
- Install it with the web installer: https://expressiveos-flash.daryldenson-apps.workers.dev
- ExpressiveOS is signed with its own keys, so moving from DerpFest needs a clean install, which erases the phone. Back up your data first.
- XDA thread: https://xdaforums.com/t/4807490/
- Telegram: https://t.me/ExpressiveGroup
- Sources: https://github.com/ExpressiveOS
